# Анимации
FadeInUp - плавное появление контента слайда
Stagger Animation - последовательное появление карточек
Hover Effects - подъем карточек при наведении
Smooth Transitions - плавные переходы между слайдами (0.5 сек)

# Компоненты
Cards - карточки приложений, моделей, функций
Badges - технологический стек
Buttons - кнопки навигации и ссылки
Lists - маркированные списки
Icons - Bootstrap Icons

# ✨ Особенности реализации
UX/UI решения
Swipe-зоны - 15% ширины экрана по бокам для удобного переключения
Автопрокрутка - автоматический переход каждые 10 секунд (останавливается при взаимодействии)
Визуальная обратная связь - кнопки реагируют на нажатие
Плавный скролл - контент прокручивается к началу при смене слайда
Скрытие контекстного меню - на swipe-зонах для лучшего UX на мобильных

# Производительность
Lazy-free - все ресурсы встроены (нет внешних запросов, кроме CDN)
CSS Animations - GPU-ускоренные анимации
Passive Event Listeners - оптимизация touch-событий
